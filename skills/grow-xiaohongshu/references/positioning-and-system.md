# 定位与内容系统

在账号冷启动、转型、定位混乱或需要长期内容机制时读取。

## 定位画布

定位不是一句领域标签。至少要连接以下五项：

| 维度 | 要回答的问题 | 有效证据 |
| --- | --- | --- |
| 人群 | 哪类人在什么场景下会需要这个账号？ | 真实提问、搜索表达、评论需求、客户记录 |
| 任务 | 他们想理解、完成、选择或避免什么？ | 具体问题和决策，而非宽泛兴趣 |
| 价值 | 每次关注或收藏能得到什么稳定回报？ | 可展示的方法、经验、审美、资源或陪伴 |
| 差异 | 为什么由这个账号来讲？ | 专业背景、真实经历、数据、独特样本或表达视角 |
| 边界 | 哪些主题、承诺和商业动作不做？ | 能保护可信度与可持续性的明确取舍 |

如果差异只有“更真诚”“更专业”或“提供干货”，继续追问可被读者看见的证据。

## 内容支柱

建立 3 至 5 个支柱即可。每个支柱写清：

- 解决的用户任务；
- 账号能持续提供的证据或素材；
- 适合的形式与系列；
- 希望触发的下一步行为；
- 停止或重构的信号。

支柱不应只是栏目名称。让不同内容承担不同角色，例如：

- `发现`：覆盖新人会搜索或立即识别的问题；
- `价值`：提供值得收藏、复用或转发的完整答案；
- `信任`：展示过程、证据、取舍和真实限制；
- `关系`：引出具体交流，积累下一轮需求信号；
- `行动`：在价值已建立时引导合理的业务或账号动作。

同一篇可以承担多个角色，但要有一个主要目标。

## 可持续性检查

在制定频率前盘点真实约束：可用时间、素材来源、视觉制作能力、审核成本、是否需要本人出镜、商业与合规风险。发布频率以质量稳定和复盘能力为上限，不照搬固定日更或周更数字。

用内容组合而不是孤立灵感维持供给：

```text
支柱 -> 系列 -> 选题 -> 单篇角度 -> 可复用素材
```

一个系列应有明确的读者期待和变化空间；只替换名词的批量模板不算系列。

## 系统交付

长期方案可包含：

1. 一句话定位与不可替代证据；
2. 内容支柱及其角色；
3. 选题来源和素材入口；
4. 从 brief、制作、审核到发布的状态流；
5. 可持续节奏和容量限制；
6. 指标记录与复盘周期；
7. 需要当次核验的平台规则和业务边界。

不要在尚无基线时承诺具体增长结果。把第一个周期定义为探索或验证周期。
