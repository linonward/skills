# 增长实验与复盘

在账号体检、指标设计、发布复盘或制定下一轮测试时读取。

## 从目标选择指标

先确定这一阶段的主要目标，再选少量可行动指标：

| 目标 | 可观察信号 | 需要警惕 |
| --- | --- | --- |
| 触达 | 曝光、观看、搜索来源、新访客 | 触达不等于内容兑现 |
| 有效互动 | 收藏、分享、具体评论、重复提问 | 不同互动意图不能简单相加解释 |
| 信任 | 主页访问、持续阅读、关注、回访、深度讨论 | 后台不可见时不要虚构归因 |
| 业务行动 | 商品点击、私信咨询、表单、订单或其他合规动作 | 内容与后端承接可能共同影响结果 |

计算比率时明确分子、分母、数据来源和观察窗口。例如互动率按曝光还是观看计算会产生不同含义，不混用口径。

## 建立可比基线

- 使用一段时间内的同账号内容，不只比较最好和最差的一篇；
- 优先比较相同形式、相近主题、相似账号阶段和一致数据窗口；
- 同时看中位数、分布和异常值，避免均值被单条爆款支配；
- 记录缺失数据、删改、投放、联动、节假日和热点等外部因素；
- 公开竞品数据不包含其曝光、点击、投放和关注归因，结论必须降级。

## 实验卡

一次测试围绕一个主要假设，允许保留次要观察，但不要同时大改到无法解释。

```markdown
- 目标：
- 假设：如果改变 X，Y 会改善，因为 Z。
- 基线与可比组：
- 主要变量：
- 保持相对稳定的因素：
- 主要指标与护栏指标：
- 观察窗口：
- 证据达到什么程度才放大、继续、调整或停止：
- 外部影响与未知项：
```

不要从单篇胜负宣布规律。测试次数取决于发布容量和结果波动；目标是积累重复、可比较的证据，而不是达到一个任意数字。

## 诊断顺序

沿用户路径定位断点：

```text
被看见 -> 愿意点开/停留 -> 内容兑现 -> 产生互动 -> 访问主页 -> 关注或行动
```

一个指标下降可能有多种解释。先列可观察证据，再列候选原因和区分它们所需的数据。例如：

- 触达低：题目需求弱、包装不清、账号阶段、分发波动或违规风险；
- 触达高但互动弱：承诺与内容错位、答案浅、受众不准或 CTA 无关；
- 收藏高但关注弱：单篇有工具价值，但账号定位或主页承接不清；
- 互动好但业务弱：人群、信任、产品匹配或转化路径存在断点。

这些是诊断假设，不是看到数据后的自动结论。

## 复盘输出

```markdown
## 结果
- 样本、时间与数据口径：
- 相对基线的变化：

## 解释
- 可以确认的观察：
- 最可信的解释：
- 竞争解释与反证：
- 仍缺少的数据：

## 决策
- 放大 / 继续测试 / 调整 / 停止：
- 下一轮只优先改变什么：
- 要保留的内容资产或用户问题：
```

复盘的价值是改变下一次决策。没有可执行变化的指标汇总不是完整复盘。
