# 研究与选题

在站内研究、竞品拆解、趋势判断和选题池构建时读取。

## 研究设计

先写清问题，再决定样本。常见问题包括：

- 用户如何表达同一个痛点？
- 哪类内容吸引点击，哪类内容促成收藏、评论或追问？
- 哪些需求被重复满足，哪些仍缺少可信答案？
- 当前账号的弱点来自选题、包装、内容兑现还是承接？

优先组合三种样本：

- `相关热门`：寻找已被验证的需求与包装模式；
- `近期内容`：降低只研究历史爆款造成的时效偏差；
- `可比账号`：选择体量、定位或资源条件接近的创作者。

记录检索词、采样时间、筛选方式和可见字段。访问受限时，请用户提供链接、截图、导出数据或手工样本；不要补造搜索结果。

## 拆解字段

对代表性笔记观察：

- 面向的人群、场景、任务和情绪；
- 标题承诺与封面信息层级；
- 开头如何建立相关性；
- 正文的证据、步骤、冲突或叙事推进；
- 图片或视频分别承担什么信息功能；
- CTA 引出了什么类型的评论；
- 评论区出现的追问、反对、误解和未满足需求；
- 可见互动与发布时间等上下文。

先写观察，再写解释。不要把“高收藏”直接翻译成“平台偏爱”，也不要从单篇内容推出稳定算法规律。

## 从模式到原创选题

可复用的是需求和机制，不是表达本身。把样本转换为：

```text
人群 + 具体场景 + 未解决任务 + 可提供证据 + 适合形式
```

选题评分使用相对判断，不伪造精确科学性：

- `相关性`：目标人群是否会立即认出这是自己的问题；
- `账号契合`：是否支持定位与内容支柱；
- `新增价值`：是否有新证据、新解释、新方法或更好的边界；
- `可证明性`：是否有足够材料兑现承诺；
- `可包装性`：视觉和标题能否准确传达核心价值；
- `可延展性`：能否发展为系列并产生后续问题；
- `风险与成本`：制作、版权、合规和验证成本是否合理。

## 选题卡

每个优先选题至少包含：

```markdown
- 服务人群与场景：
- 用户任务：
- 核心承诺：
- 新增价值或证据：
- 内容角色：发现 / 价值 / 信任 / 关系 / 行动
- 推荐形式：单图 / 多图 / 视频 / 长文
- 标题与封面方向：
- 希望验证的假设：
- 风险或未知项：
```

热点只在与账号定位、读者任务和可提供证据同时相交时使用。没有独特增量时，放弃跟进比强行蹭热点更有价值。
