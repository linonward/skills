# 笔记与视觉发布包

在创作或改写图文笔记、视频脚本、标题、封面和多图卡片时读取。

## 单篇任务书

动笔前确认：目标读者、具体场景、唯一主要目标、核心承诺、可用证据、作者声音、形式、风险边界。信息不足但不影响立场和真实性时可以作出明确假设；需要个人经历、产品体验或专业结论才能成立时必须索取材料或缩小主张。

## 包装顺序

把标题、封面、开头和正文当成同一个承诺链：

```text
标题指出相关性 -> 封面压缩价值 -> 开头确认场景 -> 正文兑现 -> CTA 承接下一步
```

- 标题应让目标人群识别问题、收益或判断，不堆叠夸张词。
- 封面优先传达一个信息焦点；它可以补充标题，但不重复塞满正文。
- 开头尽快确认“为什么与你有关”，无需强制反问、冲突或个人故事。
- 正文结构由任务决定：步骤、清单、比较、案例、复盘、观点或故事都可使用。
- CTA 应与内容角色一致。教程可邀请具体问题，观点可邀请边界案例，业务内容可给出透明且合规的下一步。

## 图文与多图卡片

每张图只承担一种主要功能：吸引、说明、对比、证明、导航或行动。多图卡片可用以下节奏，但不应机械套用：

1. 封面：谁的问题和什么价值；
2. 情境：为什么现在需要；
3. 核心答案：先给结论或路线；
4. 展开：步骤、示例、对比或证据；
5. 收束：边界、总结或下一步。

为每张图给出画面目标、主文案、支持信息、素材来源、版式层级和替代文本。真实人物、产品效果、前后对比、成绩截图和用户评价必须可追溯且获得合理授权。

## 视频脚本

视频包按需要包含：首屏信息、口播或动作脚本、镜头功能、字幕重点、素材需求、节奏转折和 CTA。不要用固定秒数替代对内容密度的判断；首屏承诺必须在视频中得到兑现。

## 话题与搜索表达

把用户实际会搜索的自然表达放在标题、封面或正文关键位置，前提是可读且准确。话题标签用于分类和补充语境，不用无关热门标签堆量。数量与选择应根据当前内容和平台能力判断，不写成永恒公式。

## 输出模板

```markdown
## 发布目标
- 人群与场景：
- 主要目标：
- 核心承诺：

## 候选包装
- 推荐标题：
- 备选标题：
- 封面文案与视觉方向：

## 正文或脚本
...

## 视觉清单
- 位置 / 功能 / 内容 / 素材来源 / 替代文本

## 发布元素
- 话题：
- CTA：

## 实验卡
- 假设：
- 本轮主要变量：
- 观察指标与窗口：
```

用户明确要求实际出图时，再调用可用图片工具并检查文字可读性、裁切安全区、人物与产品真实性。没有工具时交付可直接使用的提示词，不宣称已生成。
